# HTML & CSS Practice Project

## About

This project is a simple registration form created to practice HTML and CSS concepts. It includes different input fields, buttons, icons, and a responsive layout. The project helped me improve my understanding of form creation, styling, Flexbox, and media queries.

## Features

* Registration form design
* User name, email, phone number, and seat selection inputs
* Font Awesome icons
* Submit and Cancel buttons
* Responsive design for different screen sizes
* Clean and simple user interface

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## What I Practiced

* HTML form elements
* Input types (`text`, `email`, `tel`, `number`)
* CSS styling
* Flexbox layout
* Responsive web design
* Media queries
* Using external icon libraries

## Project Purpose

The main purpose of this project is to strengthen my HTML and CSS skills by building a simple and responsive form layout from scratch.
